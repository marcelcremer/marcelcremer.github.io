# CLAUDE.md

Dieses Repo ist die persönliche GitHub-Pages-Seite von Marcel Cremer (`marcelcremer.github.io`), veröffentlicht als GitHub Pages (Source: `main`, root).

## Workflow

- Arbeite auf einem Feature-Branch, niemals direkt auf `main`.
- Committe die Änderungen mit klaren, beschreibenden Commit-Messages.
- Push den Branch nach `origin`.
- Erstelle am Ende der Arbeit **immer** einen Pull Request nach `main` (auch bei kleinen Änderungen) — kein direkter Merge ohne PR.
- Schau dir den Diff des PRs selbst noch einmal an, bevor du ihn als fertig meldest.
- Merge den PR nicht automatisch; das entscheidet der Repo-Owner.
